# DAILY DESK

天気・全国と地域のニュース・野球・男子サッカー日本代表をまとめる日本語ダッシュボード。GitHub Pagesで公開する静的サイトです。

## ローカル確認

Node.js 22以上で実行します。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

http://localhost:3000 を開きます。使用中なら `PORT=3100 npm run dev`。GitHub Pagesと同じサブディレクトリで確認する場合は `BASE_PATH=/japan-sports-desk PORT=3100 npm run dev` を実行します。

`npm run build` が無料の公開情報を取得し、`dist/` にHTML・CSS・JavaScript・`data/sports.json`を生成します。ローカルでデータを更新するには、このコマンドを再実行してください。サーバーは生成済みファイルを配信するだけです。

## 公開と自動更新

公開先: https://ryuusei-works.github.io/japan-sports-desk/

- リポジトリは公開設定、Settings → Pages → Sourceは **GitHub Actions**。
- `main`へのプッシュでテスト・データ取得・静的サイト生成・Pages公開を自動実行。
- 毎時11分・41分（UTC。日本時間も同じ分）にデータ更新用のワークフローを実行予定。
- Actions → Publish sports dashboard → Run workflowでも更新可能。
- `dist/`のみを公開し、生成データはGitへコミットしません。
- テストが失敗した場合や、公開データがすべて取得できない場合は、前回の公開を維持します。一部の取得失敗は該当欄に明示します。

ワークフロー: [.github/workflows/pages.yml](.github/workflows/pages.yml)。GitHubの短期トークンと公式Pagesアクションを使い、手動のAPIキー登録や外部サービスとの契約は不要です。公式アクションはコミットIDで固定しています。

公開リポジトリの標準GitHubホストランナーを使います。有料プラン・大容量ランナー・独自ドメイン・Vercelは使用しません。

GitHubのスケジュール実行は遅延・停止する場合があります。公開リポジトリで60日間活動がない場合は定期実行が自動停止されるため、Actionsで再有効化してください。画面は取得日時を表示し、2時間以上経過したデータには注意表示を出します。

## 機能

- ヘッダーのボタンで左メニューを開閉でき、状態はブラウザー内に保存します。左サイドバーから「ホーム」「野球」「サッカー日本代表」「野球集計」「設定」の5タブに切り替え。各タブの直リンクと、ブラウザーの戻る・進む、キーボード操作に対応します。使い方は「使い方・更新について」リンクから開きます。
- ホーム上部に47都道府県の地域選択、気象庁の短期天気予報（掲載分・最大3日）、Yahoo!ニュースの全国／地域ニュース各3件を切り替えて表示。位置情報は取得せず、地域選択はlocalStorageとJSONバックアップで保存します。
- 気象庁の代表予報区を使用（北海道は札幌周辺、鹿児島と沖縄は本島周辺）。予報区域と気温の地点を明記。未掲載の気温・降水確率は「—」。降水確率は掲載時間帯の最大値で、現在の観測値ではありません。地域ニュースは選択した都道府県の地方紙・放送局のYahoo!配信を使い、配信元を明記します。近隣地域や全国の記事を含む場合があります。
- ホームの「スポーツの予定・カレンダー」を開くと、今日と今週（月曜〜日曜・日本時間）の試合を表示。終了・中止も明示し、取得失敗時は件数が取得成功分だけであることを案内します。
- ホームの開閉欄にNPBと男子日本代表の月間カレンダー。「すべて／野球／サッカー／応援球団」で月間表示と選択日の詳細を絞り込めます。野球は取得月の前月〜翌々月の4か月分を取得し、月をまたぐ週間日程にも対応。サッカーは当年の公式日程掲載分（翌年の掲載を含む）です。未発表・取得範囲外の試合は表示できません。
- 設定で5色のテーマと12球団から応援球団を選択。応援球団は次の試合の初期絞り込みとカレンダーの★表示に反映します。設定はブラウザーのlocalStorageにだけ保存し、サーバーへ送信しません。保存が制限された環境では画面を開いている間だけ反映します。
- 文字サイズの設定は削除。旧localStorageや旧JSONのfontSizeは読み込み時に無視し、テーマ・応援球団・指名は維持します。新JSONにはfontSizeを含めずregionを保存。旧JSONで地域がない場合は東京都に戻します。
- 野球ページに応援球団の終了試合を直近5件表示。NPB月間日程を最大8か月遡り、各球団の結果を確保できた時点で取得を止めます。スコア未取得・5試合未満・取得失敗を明示し、中止・試合途中は結果に含めません。
- サッカーページに前回の男子代表戦の結果と、次戦相手のFIFA順位・ポイント・日本との差・直近の日本との対戦を表示。対戦履歴は当年と過去2年のJFA公式日程が対象で、見つからない場合はその旨を表示します。PK戦は試合スコアと区別します。
- ホームは天気・全国／地域ニュースを優先し、試合関連は開閉欄にまとめます。今週の一覧・カレンダーの取得範囲と日時は開閉して確認できます。スマホのカレンダーは日付と競技別の件数を表示し、選択日の対戦カードは下に表示します。
- ヘッダーに取得・集計完了日時、各データ欄に取得日時を日本時間で表示します。
- 各スポーツページの上部にNPB・JFAの公式ニュース最新3件（見出し・掲載日・記事リンク）。本文や写真は転載せず、ニュースも30分ごとの更新対象です。
- NPBの取得月の前月〜翌々月の発表済み試合予定（CS・日本シリーズを含む）、チーム選択
- セ・パのレギュラーシーズン順位
- 打率、本塁打、打点、安打、盗塁、出塁率、防御率、勝利、勝率、奪三振、セーブ、ホールドポイント
- セ・パ別とセパ総合の10位まで。同順位は競技順位方式、10位タイを全員表示
- 球団別の個人成績はNPB掲載の対象者から球団内順位を再計算します。規定条件はリーグ順位と同じで、対象者がいない場合もあります。球団内順位は公式タイトルではありません。
- 個人成績に首位との成績差を表示。球団別でもリーグ首位と比較し、セパ総合では両リーグの首位と比較します。打率などは現在の数値差で、首位に並ぶための必要安打数ではありません。
- 応援球団の選手をリーグ全体の個人成績ランキングで色と★で強調。設定変更はすぐに反映します。
- 前回公開データと順位・成績を比較。順位表は順位・勝敗数、個人成績は順位・部門の数値差を表示します。「数字の見方」をタップすると勝率・ゲーム差・規定条件・前回比の説明を開けます。
- 打率・出塁率・防御率はNPBの規定対象者。勝率はNPB公式勝率ランキング掲載者。対象者が10人未満の場合は全員表示
- 男子日本代表の次戦（キックオフ時刻が公式日程一覧にない場合は詳細ページを案内）
- 最新公式発表のFIFA順位・ポイント・前後の国。次の代表戦の相手を自動照合し、SUM方式で勝ち・引き分け・負けのポイントと概算順位を試算します。試合種別は大会名・ステージから判定し、不明な場合は選択するまで試算しません。親善試合のウィンドウ自動判定は確認済みの2026年に対応。他の年は種別の選択が必要です。

## データの扱い

出典は https://npb.jp/ 、https://www.jfa.jp/ 、https://inside.fifa.com/ 。無料公開ページとFIFA公式ページが利用する公開エンドポイントを読み取ります。有料API・APIキー・認証・データベースは使用しません。

ブラウザーは15分ごとに公開済みJSONを読み直します。「データを再確認」でも、公式サイトへの新しい取得ジョブは起動しません。試合速報や、閲覧のたびのリアルタイム取得ではありません。FIFAは最新の公式発表を基準とし、暫定ライブ順位ではありません。

出典リンクと取得日時を表示します。仕様変更や取得制限で失敗する可能性があり、エラーを明示してダミー値は出しません。セパ総合は独自集計で公式タイトルではありません。FIFA試算は通常の勝敗のみ。日本と対戦相手のポイントを同時に増減し、その他の国を固定した概算です。PK戦・決勝トーナメントの減点免除・同ポイント時の公式順位決定は含みません。

前回比は、GitHub Actionsでビルドする際にこのサイトの公開済みJSONを読み、順位表と個人成績の前回1回分だけを新しいJSONに保存します。履歴を入れ子にせず、APIキーや有料ストレージを使いません。前回の公開取得が失敗した場合・初回・年度切り替えは「比較なし」と表示します。項目の取得失敗や前回対象外の選手も差を推測しません。これは前日比や1試合単位の変化ではなく、比較元の取得日時を画面に表示します。ローカルビルドは既存のdist内JSONを比較元にします。

試算の根拠：[FIFA算定方法](https://inside.fifa.com/fifa-rankings/world-ranking/procedure-men)、[男子国際試合カレンダー](https://inside.fifa.com/tournament-organisation/international-match-calendars)。次戦はJFA公式日程を参照します。

公開情報の再配布条件は各提供元の規約に従います。取得制限や認証の回避は行いません。提供元から制限が示された場合は取得処理を停止・変更してください。

## 安全性

生成ファイルに秘密情報やAPIキーは含めません。データ取得先は固定ホストに限定し、任意URLを受け付けません。HTMLの外部値はエスケープし、取得に12秒のタイムアウトを設けています。外部JavaScript・広告・アクセス解析・画像CDNは使いません。

GitHub PagesではHTML内のCSPとReferrer Policyを設定しています。任意のHTTPレスポンスヘッダーを設定する機能はないため、ローカルサーバーのヘッダー設定とは異なります。ローカルサーバーは127.0.0.1だけで待ち受けます。

## 検証

`npm test`で成績解析・同順位・FIFA算式・静的サイト生成・サブディレクトリのパス・全取得失敗時の動作を検証します。

`node scripts/verify-ui.mjs dist/data/sports.json`で実データを使ったDOM操作も検証できます。ブラウザーでの見た目の確認を置き換えるものではありません。

### 野球集計

- A軍・B軍の軍名を変更でき、打率・本塁打・安打・打点・勝利・防御率・セーブの7部門で各5巡を指名。球団→選手で選びます。球団別の一軍公式戦成績24ページも30分ごとに取得し、0本・0セーブも反映します。
- 本数・勝利などは合計、打率・防御率は規定対象者の表示値の単純平均。防御率は低い方、他は高い方が優勢で、部門勝数を比較。未選択・取得失敗・対象者なしは判定待ちです。
- 2026年度は同部門内で両軍の重複指名を禁止し、別部門では指名できます。2027年度以降は両軍・全7部門を通して同じ選手を指名できません。全角英数・空白を正規化した選手名で判定し、球団が異なっても同名は重複扱いです。公式の全日程終了表示と全7部門の集計完了が揃うと最終比較になります。
- 2027年度以降の保存済み指名に重複がある場合は自動削除せず、警告と該当部門の判定待ちを表示します。選び直すと解除します。
- 指名と軍名は年度ごとのlocalStorageだけに保存し、外部送信・自動同期はしません。JSONで別ブラウザーへ引き継げます。成績は保存せず取得済みの最新データを参照。移籍・改名で一致しない場合は掲載なしと表示します。

### 検索とJSON引き継ぎ

- 野球集計では球団を選んだ後、名前の一部で選手候補を検索できます。全角英数と空白を正規化し、検索中も選択済みの選手を保持します。
- 設定の「JSONを保存」でテーマ・地域・応援球団・メニュー開閉・保存済み年度の軍名／指名をダウンロード。別ブラウザーの「JSONを選んで読み込む」で内容をプレビューし、反映ボタンで読み込みます。
- 公式成績はJSONに含めず、公開中の最新データを使用。読み込んだ設定と含まれる年度だけを上書きし、それ以外の年度・サイト外の保存データは保持します。ファイルは外部に送信しません。
- 旧ルールで重複した2027年度以降の指名も、バックアップでは欠落なく保存できます。ただし読み込みは新ルールで検証するため、移行前に重複を修正して再保存してください。
- 読み込みは1MB・50年度以内、形式バージョン・球団・指名枠・年度別の重複ルールなどを検証。保存に失敗した場合は書き換え済みのキーを復元します。

### 年度・月別推移

- 集計年度を切り替え、2026・2027・2028年以降の指名を別々に保存します。翌々年までと保存済み年度を表示。未来の年度は現年度の掲載選手で仮指名でき、成績は未公開として判定しません。
- 完全取得できた球団成績・規定対象者を、各月の最後の取得時点で1スナップショット保存。前回公開JSONの履歴を引き継ぎ、過年度も保存済みの当該年度成績で集計します。過去公開データを読めない場合は公開を停止して履歴の消失を防ぎます。
- 月別表は現在の指名選手によるシーズン累計と前月差。指名を変えると過去月も再集計します。保存前の月は未記録で、月間単独成績・指名当時の履歴ではありません。
- 2026年・防御率に限り「特別枠（MLB）／今井 達也」を選択できます。計測不可として平均から除外し、MLBの成績を取得・代入しません。JSON引き継ぎもこの年度・部門の組み合わせだけ許可します。

- 定期実行が抜けた際の影響を減らすため、毎時11分・41分の2回を設定。GitHubの定期実行には時刻・実行の保証がないため、2時間を超えた古いデータの警告は維持します。公開JSONはキャッシュを使わず再取得し、タブへ戻った際も読み直します。

## 天気・一般ニュース・上位国の試合

- 天気：気象庁公開JSON。https://www.jma.go.jp/bosai/forecast/ の情報を整理して表示し、出典・発表日時・取得日時を明示。
- 全国ニュース：Yahoo!ニュースの公開RSS `https://news.yahoo.co.jp/rss/topics/top-picks.xml`。地域ニュース：Yahoo!公式RSS一覧に掲載された地方紙・放送局を47都道府県ごとに選定し、`https://news.yahoo.co.jp/rss/media/{媒体ID}/all.xml`から取得。配信元を明記し、近隣地域・全国の記事を含む場合があることを案内します。最新3件の見出し・日付・記事リンクだけを表示し、本文・画像は保存／転載しません。全国／地域の切り替え、取得日時・出典の開閉に対応します。
- 日本より上位の国：FIFA公式ランキングの順位で動的に抽出。ESPNの無料公開データ `site.api.espn.com/apis/site/v2/sports/soccer/fifa.friendly/teams` で国コードを照合し、`soccer/all/teams/{id}/schedule`（結果）と `?fixture=true`（予定）を取得。クラブや女子代表を混ぜないよう国コード・isNationalを確認します。APIキー・契約・課金処理はありません。公開エンドポイントのため将来の仕様変更・可用性の保証はありません。
- 初期表示は日本の直上3か国に絞り、「上位すべて」で全上位国を表示できます。国ごとに次の最大3試合と直近3結果を開閉表示。対戦相手の順位は最新FIFA発表時点で、試合当日の順位ではありません。試合日時は日本時間、未確定時刻・未収録・一国だけの取得失敗を明示。予定の仮スコア0は結果にせず、PKスコアも分離します。
- 野球集計は各巡の選手名・球団・現在の成績を大きく一覧表示し、球団選択・検索・選手選択はその枠を開いて編集します。月別推移・応援球団の直近結果・日本代表の前回結果や相手紹介は開閉欄に整理しています。
- 追加データもGitHub Actionsで取得し、ブラウザーは同一サイトのJSONだけを読み込みます。CSP、外部トラッキングなし、位置情報・APIキーなしの構成を維持します。
