# JAPAN SPORTS DESK

NPBと男子サッカー日本代表の日本語ダッシュボード。GitHub Pagesで公開する静的サイトです。

## ローカル確認

Node.js 22以上で実行します。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

http://localhost:3000 を開きます。使用中なら `PORT=3100 npm run dev`。GitHub Pagesと同じサブディレクトリで確認する場合は `BASE_PATH=/japan-sports-desk PORT=3100 npm run dev` を実行します。

`npm run build` が無料の公式公開情報を取得し、`dist/` にHTML・CSS・JavaScript・`data/sports.json`を生成します。ローカルでデータを更新するには、このコマンドを再実行してください。サーバーは生成済みファイルを配信するだけです。

## 公開と自動更新

公開先: https://ryuusei-works.github.io/japan-sports-desk/

- リポジトリは公開設定、Settings → Pages → Sourceは **GitHub Actions**。
- `main`へのプッシュでテスト・データ取得・静的サイト生成・Pages公開を自動実行。
- 毎時17分（UTC。日本時間も各時17分）にデータ更新用のワークフローを実行予定。
- Actions → Publish sports dashboard → Run workflowでも更新可能。
- `dist/`のみを公開し、生成データはGitへコミットしません。
- テストが失敗した場合や、公式データがすべて取得できない場合は、前回の公開を維持します。一部の取得失敗は該当欄に明示します。

ワークフロー: [.github/workflows/pages.yml](.github/workflows/pages.yml)。GitHubの短期トークンと公式Pagesアクションを使い、手動のAPIキー登録や外部サービスとの契約は不要です。公式アクションはコミットIDで固定しています。

公開リポジトリの標準GitHubホストランナーを使います。有料プラン・大容量ランナー・独自ドメイン・Vercelは使用しません。

GitHubのスケジュール実行は遅延・停止する場合があります。公開リポジトリで60日間活動がない場合は定期実行が自動停止されるため、Actionsで再有効化してください。画面は取得日時を表示し、2時間以上経過したデータには注意表示を出します。

## 機能

- 左サイドバーから「ホーム」「野球」「サッカー日本代表」「お楽しみ」「設定」の5タブに切り替え。各タブの直リンクと、ブラウザーの戻る・進む、キーボード操作に対応します。使い方は「使い方・更新について」リンクから開きます。
- ホームに今日と今週（月曜〜日曜・日本時間）の試合を表示。終了・中止も明示し、取得失敗時は件数が取得成功分だけであることを案内します。
- 応援球団のまとめカードに次戦・順位・首位とのゲーム差・打率、本塁打、打点、勝利、防御率、奪三振の球団トップを表示。同率トップは全員表示し、規定条件は既存ランキングと同じです。
- ホームはNPBと男子日本代表の月間カレンダー。「すべて／野球／サッカー／応援球団」で月間表示と選択日の詳細を絞り込めます。野球は取得月の前月〜翌々月の4か月分を取得し、月をまたぐ週間日程にも対応。サッカーは当年の公式日程掲載分（翌年の掲載を含む）です。未発表・取得範囲外の試合は表示できません。
- 設定で5色のテーマと12球団から応援球団を選択。応援球団は次の試合の初期絞り込みとカレンダーの★表示に反映します。設定はブラウザーのlocalStorageにだけ保存し、サーバーへ送信しません。保存が制限された環境では画面を開いている間だけ反映します。
- 文字サイズは「標準／大きめ」を設定・保存できます。大きめでは順位表、ニュース、説明文などを拡大し、横に長い表はスクロールできます。テーマや応援球団の既存設定は維持します。
- 野球ページに応援球団の終了試合を直近5件表示。NPB月間日程を最大8か月遡り、各球団の結果を確保できた時点で取得を止めます。スコア未取得・5試合未満・取得失敗を明示し、中止・試合途中は結果に含めません。
- サッカーページに前回の男子代表戦の結果と、次戦相手のFIFA順位・ポイント・日本との差・直近の日本との対戦を表示。対戦履歴は当年と過去2年のJFA公式日程が対象で、見つからない場合はその旨を表示します。PK戦は試合スコアと区別します。
- お楽しみタブに注目選手くじと手動の3×3観戦ビンゴ。くじは応援球団の取得できた今季公式成績掲載選手を部門間で重複除去して抽選し、掲載部門の数値を表示します。出場予定・活躍予測ではありません。同じ日に何度でも引けます。ビンゴは自己申告でチェックし、再タップで解除、リセットが可能。中央FREEを含む達成ライン数を表示します。
- 最後に引いた今日の選手とビンゴのチェックはブラウザー内だけに保存。日付・年度・応援球団が異なる選手は復元しません。ビンゴは自分でリセットするまで継続します。保存が制限されても画面内で遊べます。アカウント・有料API・有料ストレージを追加しません。
- 各画面上部に取得・集計完了日時、各データ欄に取得日時を日本時間で表示します。
- 各スポーツページの上部にNPB・JFAの公式ニュース最新6件（見出し・掲載日・記事リンク）。本文や写真は転載せず、ニュースも毎時の更新対象です。
- NPBの直近3か月の発表済み試合予定（CS・日本シリーズを含む）、チーム選択
- セ・パのレギュラーシーズン順位
- 打率、本塁打、打点、安打、盗塁、出塁率、防御率、勝利、勝率、奪三振、セーブ、ホールドポイント
- セ・パ別とセパ総合の10位まで。同順位は競技順位方式、10位タイを全員表示
- 球団別の個人成績はNPB掲載の対象者から球団内順位を再計算します。規定条件はリーグ順位と同じで、対象者がいない場合もあります。球団内順位は公式タイトルではありません。
- 個人成績に首位との成績差を表示。球団別でもリーグ首位と比較し、セパ総合では両リーグの首位と比較します。打率などは現在の数値差で、首位に並ぶための必要安打数ではありません。
- 応援球団の選手をリーグ全体の個人成績ランキングで色と★で強調。設定変更はすぐに反映します。
- 前回公開データと順位・成績を比較。順位表は順位・勝敗数、個人成績は順位・部門の数値差を表示します。「数字の見方」をタップすると勝率・ゲーム差・規定条件・前回比の説明を開けます。
- 打率・出塁率・防御率はNPBの規定対象者。勝率はNPB公式勝率ランキング掲載者。対象者が10人未満の場合は全員表示
- 男子日本代表の次戦（キックオフ時刻が公式日程一覧にない場合は詳細ページを案内）
- 最新公式発表のFIFA順位・ポイント・前後の国。次の代表戦の相手を自動照合し、SUM方式で勝ち・引き分け・負けのポイントと概算順位を試算します。試合種別は大会名・ステージから判定し、不明な場合は選択するまで試算しません。親善試合のウィンドウ自動判定は確認済みの2026年に対応。他の年は種別の選択が必要です。

## データの扱い

出典は https://npb.jp/ 、https://www.jfa.jp/ 、https://inside.fifa.com/ 。無料公開ページとFIFA公式ページが利用する公開エンドポイントを読み取ります。有料API・APIキー・認証・データベースは使用しません。

ブラウザーは15分ごとに公開済みJSONを読み直します。「データを再確認」でも、公式サイトへの新しい取得ジョブは起動しません。試合速報や、閲覧のたびのリアルタイム取得ではありません。FIFAは最新の公式発表を基準とし、暫定ライブ順位ではありません。

出典リンクと取得日時を表示します。仕様変更や取得制限で失敗する可能性があり、エラーを明示してダミー値は出しません。セパ総合は独自集計で公式タイトルではありません。FIFA試算は通常の勝敗のみ。日本と対戦相手のポイントを同時に増減し、その他の国を固定した概算です。PK戦・決勝トーナメントの減点免除・同ポイント時の公式順位決定は含みません。

前回比は、GitHub Actionsでビルドする際にこのサイトの公開済みJSONを読み、順位表と個人成績の前回1回分だけを新しいJSONに保存します。履歴を入れ子にせず、APIキーや有料ストレージを使いません。前回の公開取得が失敗した場合・初回・年度切り替えは「比較なし」と表示します。項目の取得失敗や前回対象外の選手も差を推測しません。これは前日比や1試合単位の変化ではなく、比較元の取得日時を画面に表示します。ローカルビルドは既存のdist内JSONを比較元にします。

試算の根拠：[FIFA算定方法](https://inside.fifa.com/fifa-rankings/world-ranking/procedure-men)、[男子国際試合カレンダー](https://inside.fifa.com/tournament-organisation/international-match-calendars)。次戦はJFA公式日程を参照します。

公開情報の再配布条件は各提供元の規約に従います。取得制限や認証の回避は行いません。提供元から制限が示された場合は取得処理を停止・変更してください。

## 安全性

生成ファイルに秘密情報やAPIキーは含めません。データ取得先は固定ホストに限定し、任意URLを受け付けません。HTMLの外部値はエスケープし、取得に12秒のタイムアウトを設けています。外部JavaScript・広告・アクセス解析・画像CDNは使いません。

GitHub PagesではHTML内のCSPとReferrer Policyを設定しています。任意のHTTPレスポンスヘッダーを設定する機能はないため、ローカルサーバーのヘッダー設定とは異なります。ローカルサーバーは127.0.0.1だけで待ち受けます。

## 検証

`npm test`で成績解析・同順位・FIFA算式・静的サイト生成・サブディレクトリのパス・全取得失敗時の動作を検証します。

`node scripts/verify-ui.mjs dist/data/sports.json`で実データを使ったDOM操作も検証できます。ブラウザーでの見た目の確認を置き換えるものではありません。
