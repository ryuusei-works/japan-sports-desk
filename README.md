# JAPAN SPORTS DESK

NPBと男子サッカー日本代表の日本語ダッシュボード。Node.js 22以上。

```sh
npm ci
npm run dev
```

http://localhost:3000 を開きます。使用中の場合は `PORT=3100 npm run dev`。

## 機能

- NPBの直近3か月の発表済み試合予定（CS・日本シリーズを含む）、チーム選択
- セ・パのレギュラーシーズン順位
- 打率、本塁打、打点、安打、盗塁、出塁率、防御率、勝利、勝率、奪三振、セーブ、ホールドポイント
- セ・パ別、セパ合算の各10位まで。同順位は競技順位方式、10位タイを全員表示
- 打率・出塁率・防御率はNPBの規定対象者、勝率はNPB公式勝率ランキング掲載者を使用。対象者が10人未満なら人数分のみ表示
- JFA公式の男子日本代表の次戦（公式日程にキックオフ時刻がないときは詳細へのリンクを案内）
- FIFA最新公式発表の日本の順位・ポイント・前後の国、上位国との差、SUM方式の試算

## データと更新

取得先は https://npb.jp/ 、https://www.jfa.jp/ 、https://inside.fifa.com/ 。無料公開ページとFIFA公式ページが利用する公開エンドポイントを読み取ります。有料API・キー・認証・データベース不要。公開ページの仕様変更や制限で取得できなくなる可能性があります。取得エラーは明示し、ダミー値は表示しません。

閲覧時と表示中の15分ごとにアプリのAPIを確認し、サーバーは正常データを1時間キャッシュ。失敗時は1分後に再試行できます。閉じている間の巡回やライブ速報ではありません。FIFAは最新の公式発表であり暫定ライブ順位ではありません。

出典リンクと取得日時を画面に表示。セパ総合は独自の比較ランキングで、公式タイトルではありません。FIFA試算は通常の勝敗のみで、PK戦と決勝トーナメントの減点免除を含まず、他国の結果は固定と仮定します。

## 安全性

ブラウザーは同一オリジンのAPIのみ使用。取得先は固定ホストに限定し、任意URLを受け付けません。HTMLの外部値は表示前にエスケープ。リクエストに12秒の上限、同時取得数を制限。外部JavaScript、広告、トラッキング、画像CDNなし。ローカルは127.0.0.1だけで待ち受けます。

公開情報であることと再配布の許諾は別のため、公開前には各提供元の利用条件と最新の取得可否を再確認してください。取得制限や認証の回避は行いません。

## 検証

```sh
npm test
```

ローカルサーバーの取得結果をJSONに保存すると、`node scripts/verify-ui.mjs <JSONのパス>` で実データを使ったDOM操作の検証もできます。この検証はブラウザーでの見た目の確認を置き換えるものではありません。

## Vercel公開（画面承認後に実施）

GitHubのリポジトリをVercelの個人用HobbyプランでImportします。GitHub Appのアクセスはこのリポジトリだけを選択してください。Production Branchを `main` に設定すると、以後の `git push origin main` で本番サイトが自動更新されます。Importは初回の公開を伴うため、ローカル画面の承認後に実施します。

Framework PresetはOther、Install Commandは `npm ci`、Build Commandは `npm test`、Output Directoryは `public`。これらはvercel.jsonに定義してあります。環境変数や有料の追加サービスは不要です。ルートのapi/sports.mjsがNode関数です。テストが失敗するとビルドは失敗し、その変更は公開されません。

GitHub Actionsでのデプロイは使わず、VercelのGit連携を利用するため、デプロイ用トークンをGitHubへ登録する必要もありません。無料枠の利用量・関数実行時間に従います。料金プランの変更や課金設定は行いません。APIキーを画面やリポジトリへ置かないでください。

初回のGit接続・Vercel連携は別途完了確認が必要です。設定ファイルだけでは自動公開は有効になりません。
