# Hibi Note（ヒビノート）

全国・地域のYahoo!ニュースと、野球・サッカー日本代表をまとめる個人向けダッシュボードです。

## 公開と開発

- Vercel: https://japan-sports-desk.vercel.app/ （既存URLを継続）
- GitHub: https://github.com/ryuusei-works/hibi-note
- バックアップ公開: https://ryuusei-works.github.io/hibi-note/

Node.js 22.xで実行します。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

http://localhost:3000 を開きます。使用中なら `PORT=3101 npm run dev`。

## Vercelの設定

GitHubリポジトリのProduction Branchは`main`。Framework PresetはOther、Root Directoryはリポジトリ直下。`vercel.json`でビルドコマンド・出力先`dist`・東京リージョン・Functionの実行時間を指定します。既存画面を活かした静的フロントエンドとNode.js Functionの構成です。追加のAPIキーやDBは不要です。mainへのpushで自動デプロイします。

- `GET /api/data`は取得済みデータを返し、新規収集は開始しません。
- 「最新情報に更新」は`POST /api/data`で公開元を再取得。ログイン不要。5分以内の再操作は取得済みデータを表示します。
- 同一サイトのOrigin・専用ヘッダーを確認し、本文・任意の取得先URL・個人設定は受け付けません。固定の公開元にHTTPSで接続し、リダイレクトを拒否します。認証付きのAPIではないため、独自クライアントからのアクセス自体を防ぐものではありません。
- Vercel公式Runtime Cacheで結果と取得間隔を共有し、インスタンス内の同時処理も共有します。原子的ロックではないため、複数の新規インスタンスの同時起動で取得が重なる可能性があります。キャッシュエラー時は新規収集を止めます。
- 手動収集では専用キャッシュを使い、過去の1時間キャッシュを使い回しません。全体の取得期限は180秒、Functionは240秒。レスポンス4MB・圧縮キャッシュ1.9MBを上限とし、全取得失敗・サイズ超過時は前回のデータを保持します。一部の失敗は該当欄に明示します。
- 15分ごととタブに戻った際の自動再読込は、取得済みデータの確認です。2時間以上古い場合は案内を表示します。公式の速報ではありません。

## ニュース・スポーツ・集計

- 全国と47都道府県の地域ニュースを各3件。記事の見出し・日付・配信元リンクを掲載し、本文・写真は転載しません。「あとで読む」は端末内に保存します。
- ホームに今日・今週の試合と月間カレンダー。終了試合はスコア、未取得時は理由を表示し、予定・中止・試合中を区別します。スマホでは日付を選んで下部の詳細を確認できます。
- 野球はセパ順位、12部門の個人ランキング（10位タイまで）、球団別・セパ総合、前回比、応援球団の結果。未設定の場合も最近終了した試合を表示します。
- サッカーは次戦と前回結果、相手紹介、公式FIFAランキング、上位国の予定・結果、勝敗によるポイント試算。
- 野球集計は7部門・各軍5巡。年度別の軍名・指名、検索、編集ロック、比較、月次推移。2027年度以降は両軍・全部門で重複指名を防止します。2026年度の今井の防御率は特例選択・計測不可です。
- 天気・気象情報の画面と取得処理は削除しました。地域選択はニュース用に継続します。
- 「使い方・更新について」から、ニュース・予定と結果・指名・データ移行・更新・成績の読み方を確認できます。

## 保存データと月次履歴

設定・指名・ロック状態・保存ニュースはlocalStorageにのみ保存し、サーバーへ送信しません。名称変更では保存キーとJSON形式の識別子を維持します。古いJSONの文字サイズと天気の表示設定は無視し、それ以外を引き継ぎます。別ブラウザーや別ドメインへの移行は、設定からJSONを保存・読み込みしてください。

GitHub Actionsはmainへのpush・手動・毎時11分/41分に無料の公開情報を収集し、Pagesへバックアップ公開します。VercelのHobby Cronに30分間隔を設定していません。Actionsの時刻や実行は保証されず、遅延する場合があります。

月次履歴は原則Pagesからビルド時・実行時に引き継ぎます。リポジトリ名称変更の初回公開のため、移行前の公開済み成績だけを`data/draft-history.json`に保存しています。新旧Pagesがともに404の場合だけ、この履歴で初回公開します。通信エラーや異常な履歴形式はデプロイを止めます。Vercelのキャッシュは恒久保存先ではなく、手動収集だけの履歴は次の定期収集まで永続化されません。

## 無料枠と検証

有料API・有料DB・トラッキング・位置情報取得は追加していません。Vercel Hobbyの個人・非商用利用と無料枠を前提にし、無制限の無料運用は保証しません。アクセスが増えた場合はVercel Usageを確認してください。

`npm test`で取得処理・保存/移行・成績・更新APIを検証し、実データの画面検証は`node scripts/verify-ui.mjs dist/data/sports.json`で実行します。CSP・Referrer Policy・機器アクセス制限などをVercelのレスポンスヘッダーで設定しています。
